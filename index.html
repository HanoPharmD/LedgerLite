Data & Privacy
Your data lives on
your device, not ours
LedgerLite has no server. No cloud. No subscription. Here's exactly how it works.
🌐 Web Version

Browser-based

Data is stored in your browser's localStorage — the same place browsers save settings and preferences. It persists between sessions on the same browser and device.

Limitation: data doesn't sync across devices or browsers. Use the Backup button to export a JSON file and Restore it on another device.

🖥️ Desktop App

Native app via Electron

The desktop app stores data in your OS user profile — a permanent location on disk that isn't affected by browser cache clearing or updates.

Data path: Windows: %APPDATA%\ledgerlite
Mac: ~/Library/Application Support/ledgerlite

⚡ The AI Insights feature does require an internet connection — it sends a structured summary of your financial data (no raw transaction descriptions) to Claude for analysis. No data is stored by Anthropic between sessions.
