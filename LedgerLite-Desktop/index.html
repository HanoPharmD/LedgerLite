How LedgerLite works: Upload a bank statement (CSV or Excel) and LedgerLite will categorize each transaction as Income or Expense. The first time, you walk through it manually. After that, your rules auto-apply to every future upload.

🗂️
Select a template for this upload. A template is a saved set of rules that maps keywords in transaction descriptions to categories (e.g. "cvs pharmacy" → Expense: Supplies). All files you upload in this session will be auto-categorized using the selected template's rules. You can create and manage templates under the ⚙️ Manage Template tab.
